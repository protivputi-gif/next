# Nexus AI Agent System

**Nexus** — это автономная мультиагентная система с графовым интеллектом, работающая на локальном оборудовании (включая старые ноутбуки). Система объединяет несколько специализированных агентов, управляемых единым графовым оркестратором, с поддержкой мультимодальности, самообучения и мета-познания.

## 🚀 Ключевые возможности

*   **Графовая память:** Хранение знаний в виде связанного графа сущностей для глубокого контекстного понимания.
*   **Мета-познание (Tree of Thoughts):** Агент генерирует и оценивает несколько стратегий решения перед действием, выбирая оптимальную.
*   **Модель мира:** Внутреннее представление состояния среды для предсказания последствий действий.
*   **Графовый оркестратор (DAG):** Динамическое планирование задач с поддержкой параллельного выполнения и зависимостей.
*   **Полная асинхронность:** Неблокирующая обработка запросов и операций с БД через `asyncio` + `Quart` + `aiosqlite`.
*   **Параллельное выполнение:** Одновременный запуск независимых узлов графа задач через `asyncio.gather()`.
*   **Мультимодальность:** Поддержка изображений, текста и файлов (совместимость с Llava, GPT-4o, NVIDIA NIM).
*   **Полная автономность:** Самостоятельная установка недостающих пакетов и диагностика среды.
*   **Гибридные модели:** Работа с локальными (Ollama) и облачными (OpenAI, NVIDIA, Groq) моделями.
*   **Веб-интерфейс:** Управление агентами, визуализация графа памяти и дерева размышлений в реальном времени.

## 🛠️ Установка на Ubuntu

Система устанавливается вручную из репозитория. Требуется Python 3.8+ и доступ к интернету для загрузки моделей/зависимостей.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/protivputi-gif/next.git
cd next
```

### 2. Создайте виртуальное окружение (рекомендуется)

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install quart aiohttp requests aiosqlite
```
*Примечание: Система использует **Quart** (асинхронный порт Flask) для полноценной параллельной обработки запросов, **aiosqlite** для неблокирующей работы с базой данных и стандартные библиотеки Python для асинхронности.*

### 4. Запуск системы

```bash
python agent.py
```

После запуска откройте браузер и перейдите по адресу:
👉 **http://127.0.0.1:5000**

## ⚙️ Настройка и использование

### Добавление агентов и выбор ролей
Через веб-интерфейс создайте агентов, распределяя роли в зависимости от возможностей моделей. Для максимальной эффективности рекомендуется следующая конфигурация:

| Модель | Рекомендуемая роль | Описание задачи |
| :--- | :--- | :--- |
| **meta/llama-3.1-8b-instruct** | **👑 BOSS (Planner)** | **Главный агент.** Отвечает за декомпозицию задач, построение графа и управление потоком. Добавляйте его **первым**. |
| **moonshotai/kimi-k2-instruct** | **💻 Senior Coder** | Написание сложного кода, рефакторинг, работа с большими файлами. |
| **meta/llama-4-maverick-17b...** | **🔬 Researcher** | Решение нестандартных задач, анализ архитектуры, изучение новых библиотек. |
| **mistralai/mistral-nemotron** | **🛡️ Reviewer** | Проверка кода на ошибки, безопасность, написание документации. |
| **nvidia/nemotron-mini-4b...** | **⚡ Runner** | Быстрое выполнение рутинных команд, чтение файлов, проверка логов. |

**Как добавить:**
1.  **Имя:** Уникальное имя (например, `Boss`, `Coder`, `Reviewer`).
2.  **Роль:** Краткое описание (например, "Ты главный архитектор...").
3.  **Модель:** Выберите из списка выше.
4.  **URL:** `https://integrate.api.nvidia.com/v1`
5.  **API Key:** Ваш личный ключ для соответствующей модели.

> **Совет:** Первым всегда добавляйте агента с ролью **BOSS**. Система использует первого доступного агента для первичного планирования задачи.

### Решение задач
1.  Введите задачу в поле ввода.
2.  При необходимости прикрепите изображение или файл.
3.  Нажмите **Запустить**.
4.  Наблюдайте за процессом в консоли:
    *   **Дерево размышлений:** Просмотр альтернативных планов и причин выбора текущего.
    *   **Граф памяти:** Визуализация новых связей и сущностей, созданных в процессе решения.
    *   **Логи инструментов:** Выполнение кода, команды shell, работа с файлами.

## 🏗️ Архитектура

Система состоит из двух файлов:
1.  **`agent.py`**: Ядро системы. Содержит асинхронный веб-сервер **Quart**, движок мультиагентов, графовую базу знаний (**aiosqlite**), планировщик DAG и инструменты исполнения. Все обработчики запросов и операции с БД являются асинхронными для максимальной производительности.
2.  **`index.html`**: Клиентская часть. Интерфейс управления, визуализация данных и потоковый вывод логов.

### Технологический стек
*   **Язык:** Python 3.8+
*   **Веб-сервер:** **Quart** (асинхронный фреймворк, совместимый с API Flask)
*   **Асинхронность:** Полная поддержка `asyncio` на всех уровнях — от обработки HTTP-запросов до работы с БД
*   **База данных:** **aiosqlite** для неблокирующей работы с SQLite
*   **Память:** Графовая структура данных в оперативной памяти + персистентное хранение в SQLite
*   **LLM Integration:** Универсальный адаптер под OpenAI-compatible API
*   **Параллелизм:** Одновременное выполнение узлов графа задач через `asyncio.gather()`
*   **Безопасность:** Базовая фильтрация команд, режим "Human-in-the-loop" (опционально)

## ⚠️ Важные замечания

*   **Безопасность:** Агент имеет доступ к файловой системе и может выполнять команды оболочки. Не запускайте систему с правами root и не доверяйте ей критически важные данные без присмотра.
*   **Ресурсы:** Для работы с локальными моделями (Ollama) требуется достаточный объем ОЗУ (минимум 8 ГБ рекомендовано для моделей 7B+).
*   **Сеть:** Для работы с удаленными моделями необходим стабильный доступ в интернет.
