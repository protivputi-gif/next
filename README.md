# Nexus Multi-Agent System

**Nexus** — это автономная мультиагентная система с графовым интеллектом, мета-познанием (Tree of Thoughts), DAG-оркестратором задач и поддержкой мультимодальности. Система объединяет несколько специализированных агентов, управляемых единым графовым оркестратором, с поддержкой самообучения, рефлексии и исправления ошибок.

## 🚀 Ключевые возможности

*   **Графовая память (GraphMemory):** Хранение знаний в виде связанного графа узлов (события) и рёбер (связи) в SQLite через `aiosqlite`. Поддержка эпизодического обучения и извлечения уроков.
*   **Мета-познание (Tree of Thoughts):** Агент генерирует 3 стратегии решения на английском языке, оценивает их по критериям (успех, ресурсы, безопасность) и выбирает оптимальную перед действием.
*   **Рефлексия и Self-Healing:** Анализ ошибок, извлечение уроков после каждой задачи, автоматическое построение плана восстановления при неудаче.
*   **Графовый оркестратор (DAG):** Динамическое планирование задач с поддержкой параллельного выполнения независимых узлов через `asyncio.gather()`.
*   **Полная асинхронность:** Неблокирующая обработка запросов и операций с БД через `asyncio` + `Quart` + `aiosqlite`.
*   **English System Prompts:** Все системные инструкции переведены на английский для максимальной совместимости с instruct-моделями (NVIDIA NIM, Llama, Mistral).
*   **6 Инструментов:** 
    - `run_python`: Выполнение Python-кода в песочнице
    - `run_shell`: Выполнение shell-команд (с корректной обработкой timeout через `asyncio.wait_for`)
    - `install_pkg`: Установка пакетов (pip/apt) с автоопределением менеджера
    - `read_file` / `write_file`: Работа с файловой системой
    - `fetch_url`: Загрузка контента из интернета
*   **Мультимодальность:** Поддержка изображений (base64) в чате, совместимость с Llava, GPT-4o, NVIDIA NIM.
*   **Веб-интерфейс:** Минималистичный дизайн (тёмная тема), 80% экрана — чат с агентом, плавные анимации, боковая панель для управления агентами и памятью.

## 🔧 Исправленные ошибки (v2.1)

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `Process.communicate() got an unexpected keyword argument 'timeout'` | В Python 3.12 `communicate()` не принимает `timeout` напрямую | Обёрнуто в `asyncio.wait_for(proc.communicate(), timeout=sec)` с обработкой `TimeoutError` |
| `'list' object has no attribute 'get'` | LLM возвращала план как список строк вместо `[{\"action\": ...}]` | Добавлена валидация `isinstance(step, dict)` с пропуском неверных шагов |
| `missing 1 required positional argument: 'package_manager'` | Метод `install_pkg` требовал обязательный аргумент | Изменена сигнатура на `package_manager='pip'` по умолчанию |
| `Extra data: line X column Y` / `Invalid control character` | LLM возвращала JSON с лишним текстом или некорректными символами | **v2.1:** Все системные промты переведены на английский + улучшен regex парсинг JSON |
| `planner_agent` обязательный аргумент | Вызовы `execute_graph` без агента-планировщика приводили к ошибке | Параметр сделан опциональным (`None`), fallback на первого доступного агента |
| `Неизвестное действие: {'action': 'tool_name'}` | Агент передавал имя инструмента как значение вместо названия действия | Добавлено частичное совпадение имён инструментов и авто-исправление действий |
| `pip install установить` | Self-healing извлекал имя пакета на русском языке | Все команды и имена пакетов теперь генерируются только на английском |

## 🛠️ Установка

### Требования
- Python 3.10+
- NVIDIA API Key (или любой OpenAI-compatible endpoint: Ollama, Groq, OpenAI)

### Шаги установки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/protivputi-gif/next.git
    cd next
    ```

2.  **Создайте виртуальное окружение:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # Linux/Mac
    ```

3.  **Установите зависимости:**
    ```bash
    pip install quart aiohttp aiosqlite
    ```

4.  **Запустите систему:**
    ```bash
    python agent.py
    ```

5.  **Откройте веб-интерфейс:**
    👉 **http://127.0.0.1:5000**

### Переменные окружения (опционально)
```env
NVIDIA_API_KEY=nvapi-ваш_ключ
OPENAI_API_KEY=sk-ваш_ключ
BASE_URL=https://integrate.api.nvidia.com/v1
```

## ⚙️ Настройка и использование

### Добавление агентов

Через веб-интерфейс (кнопка ⚙️) создайте агентов. **Все поля заполняются на английском языке.**

Рекомендуемая конфигурация для NVIDIA NIM:

| Имя | Роль (Role) | Модель (Model) | Описание |
| :--- | :--- | :--- | :--- |
| **BOSS** | `You are the Nexus chief architect. Your task: break down complex problems into steps.` | `nvidia/nemotron-3-super-120b-a12b` | Главный архитектор. Декомпозиция задач, Tree of Thoughts, построение графа, управление потоком. Добавляйте **первым**. |
| **Runner** | `You are a Python developer. Write and execute code to solve tasks. Always use proper error handling.` | `meta/llama-3.3-70b-instruct` | Исполнитель. Написание кода, выполнение команд, работа с инструментами. Золотой стандарт для агентных задач. |
| **Scout** | `You are a research assistant. Fetch information from URLs and summarize findings concisely.` | `meta/llama-3.1-8b-instruct` | Разведчик. Быстрые запросы, проверка фактов, простые подзадачи. Низкая задержка, высокая надёжность. |

> **Важно:** 
> 1. Используйте только модели с суффиксом **-instruct**. Они оптимизированы для выполнения инструкций и генерации структурированного JSON.
> 2. **Роль (Role)** должна быть развёрнутым системным промптом на английском языке, а не коротким названием.
> 3. Копируйте примеры ролей из таблицы выше — они протестированы и дают стабильный JSON-вывод.

**Альтернативные конфигурации:**
- Если `nemotron-3-super` недоступен, используйте `meta/llama-3.3-70b-instruct` для роли BOSS.
- Для локального запуска через Ollama: `ollama pull llama3.1:8b` → модель `llama3.1:8b`.

**Как добавить:**
1.  Откройте панель агентов (⚙️).
2.  Введите:
    - **Имя**: `BOSS`, `Runner`, или `Scout`
    - **Роль**: Скопируйте готовый промпт из таблицы выше (на английском)
    - **Модель**: Точное название модели (например, `meta/llama-3.3-70b-instruct`)
    - **URL**: `https://integrate.api.nvidia.com/v1` для NVIDIA или `http://localhost:11434` для Ollama
    - **API Key**: Ваш ключ NVIDIA (начинается с `nvapi-`) или оставьте пустым для Ollama
3.  Нажмите **"Добавить"**. Система автоматически проверит доступность модели.

> **Совет:** Первым всегда добавляйте агента **BOSS** с ролью "chief architect". Система использует первого доступного агента для первичного планирования задачи.

### Примеры задач

*   *"Исследуй последние новости об ИИ и создай саммари с ссылками"*
*   *"Установи pandas, загрузи CSV-файл и построй график цен"*
*   *"Найди уязвимости в коде файла main.py и предложи исправления"*
*   *"Сравни цены на GPU на 3 сайтах и выбери лучший вариант"*

## 🏗️ Архитектура

### Файлы системы

| Файл | Строк | Описание |
|------|-------|----------|
| `agent.py` | ~1340 | Ядро: Quart-сервер, мультиагентный движок, Graph Orchestrator, 6 инструментов |
| `index.html` | ~1150 | UI: минималистичный чат, тёмная тема, анимации, боковая панель |

### Технологический стек

*   **Язык:** Python 3.10+
*   **Веб-сервер:** **Quart** (асинхронный фреймворк)
*   **Асинхронность:** Полная поддержка `asyncio` на всех уровнях
*   **База данных:** **aiosqlite** для неблокирующей работы с SQLite
*   **Память:** Графовая структура (узлы + рёбра) в RAM + персистентное хранение
*   **LLM Integration:** Универсальный адаптер под OpenAI-compatible API

## 🆕 Что нового в v2.1

### 🔤 English System Prompts
Все системные инструкции переведены на английский язык:
- Промт планировщика графа (Graph Orchestrator)
- Генерация стратегий Tree of Thoughts
- Оценка веток ToT (Success Probability, Resource Efficiency, Safety)
- ReAct цикл агента (Think → Act → Observe)

**Результат:** Модели NVIDIA NIM и Llama теперь генерируют корректный JSON без ошибок парсинга.

**Критически важно:** При добавлении агентов через веб-интерфейс:
- **Роль (Role)** должна быть полным системным промптом на английском (скопируйте из таблицы выше)
- **Модель (Model)** должна точно совпадать с названием в документации NVIDIA/Ollama
- Не используйте короткие названия ролей типа "Boss" или "Coder" — это снижает качество JSON-вывода

### 🎯 Улучшенная обработка действий
- Частичное совпадение имён инструментов (`run_shell` ≈ `shell_command`)
- Авто-исправление неправильных действий
- Логирование доступных инструментов при ошибке

### 📦 Self-Healing на английском
- Все команды установки пакетов теперь на английском (`pip install requests` вместо `pip install установить`)
- Корректное извлечение имён пакетов из ошибок Python

## ⚠️ Важные замечания

*   **Безопасность:** Агент имеет доступ к файловой системе и может выполнять команды оболочки. Не запускайте систему с правами root.
*   **Ресурсы:** Для локальных моделей (Ollama) требуется минимум 8 ГБ ОЗУ для моделей 7B+.
